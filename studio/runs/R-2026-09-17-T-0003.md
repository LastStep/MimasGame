### The one real defect found by reading

`webGLExceptionSupport: 0` in **both** `ProjectSettings.asset:799` and the `Web Release` profile
(`Web Release.asset`, `webGLExceptionSupport: 0`). `0` is `None`: exceptions are not supported at all,
and a `throw` aborts the page.

The client has four `catch` sites, all of which are dead at that setting:

| File | Catches | What is lost |
|---|---|---|
| `Net/NetClient.cs:288` | `JsonException` from `JObject.Parse(frame)` | A malformed server frame kills the page instead of logging one line |
| `Net/NetClient.cs:470` | `Exception` around `PlayerPrefs.Save()` | An IndexedDB write failure becomes fatal — on the exact path that makes a refresh rejoin work |
| `Content/ContentBootstrap.cs:61` | `ContentLoadException` | No diagnosis of a bad catalogue; just a dead page |
| `Presentation/Board/BoardView.cs:186` | `MapLoadException` | Same, for a bad map |

Put to Rohan with three options; he chose **Explicitly Thrown Exceptions Only** (Unity's own default).

## Research

Two subagents, in parallel, before any build. Findings that changed the plan:

- **Confirmed correct, needing no change:** `DispatchMessageQueue()` called unconditionally every
  frame in `NetClient.Update()` (a documented no-op on Web, required elsewhere);
  `Application.absoluteURL` as the way to read `?room=` and `?ws=` (Unity's modern replacement for a
  `window.location.search` jslib); the server's static-file ordering and Brotli headers.
- **`http://localhost` is a secure context**, so a page on `http://localhost:7777` may open
  `ws://localhost:7777/ws` with no mixed-content block. `NetClient.ResolveUrl()` maps an `http://`
  page to `ws://<host>:7777/ws` — correct for the one-process setup, and `https://` → `wss://` is
  already right for the VPS.
- **Serving `.br` without `Content-Encoding: br` does not 404** — it hands the browser Brotli bytes as
  if they were wasm, and fails at `WebAssembly.instantiate`. Worth knowing so the error is recognised.
- Neither report found a reason to expect the build itself to fail.
